# quanto_gastei_no_uber
Eu queria saber quanto eu gastava no uber mas fazer as contas de cabeça e adicionar dado por dado no app não era muito lego, então descobri que a uber emite um relatório completo mas os dados não são tratados


## Passo-a-Passo

1 - baixar seus dados da uber 
link - https://myprivacy.uber.com/exploreyourdata/download

2 - descompactar o arquivo

3 - rodar o app.py no terminal

4 - ir na pasta rider e selecionar o arquivo (trips_data.csv)

5 - vai gerar um arquivo chamado (Relatório_Uber.xlsx)

importante - faça tudo na mesma pasta. pode ser tudo na pasta rider mesmo, jogue o app.py nela que o relatório vai aparecer lá e divirta-se
